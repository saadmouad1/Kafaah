# كـفـاءة | KAFA'AH
## المنصة الوطنية لتراخيص مزاولة المهن والاعتماد المهني
### Professional Licensure & Competency Platform

منظومة رقمية متكاملة لإعداد وتأهيل المرشحين والممارسين لاجتياز امتحانات مزاولة المهن والبورد في مختلف القطاعات:
1. **القطاع الصحي والطبي**: الطب البشري، طب الأسنان، الصيدلة، التمريض، المختبرات الطبية، العلاج الطبيعي.
2. **الهندسة والتقنية**: الهندسة المدنية، المعمارية، الكهربائية، الميكانيكية، البرمجيات والأمن السيبراني.
3. **القانون والمحاماة**: رخص مزاولة المحاماة، القضاء والنيابة العامة، الاستشارات القانونية.
4. **المحاسبة والمالية**: زمالة المحاسب القانوني (SOCPA / CPA)، المحاسب الإداري (CMA).
5. **التربية والتعليم**: رخصة المعلم المهنية، الإدارة المدرسية.

---

### المميزات الرئيسية:
- **محرك Groq AI للتقييم التشخيصي**: توليد خطط مذاكرة شخصية وقياس مستوى الجاهزية.
- **محاكاة دقيقة لبيئة قاعة الامتحان (Timed Mock)**: متوافقة مع أنظمة البرومترك والمجالس الوطنية.
- **بنوك أسئلة سريرية وتطبيقية محكمة (+12,500 سؤال)** مع الشرح الكامل لكل خيار.
- **تطبيق جوال PWA فائق السرعة** يعمل بكفاءة على كافة الأجهزة.
- **لوحة تحكم لإدارة المنصة (Admin HQ)** لإدارة البنوك والمشتركين والذكاء الاصطناعي.
- **عرض الانطلاق الرسمي**: وصول مجاني كامل لمدة 3 أشهر لجميع المشتركين.

---

### التشغيل محلياً:
```bash
cd kafaah
npm install
npm run dev
```
الموقع متاح على: `http://localhost:3000`
لوحة تحكم الإدارة: `http://localhost:3000/admin`
المعالج الذكي: `http://localhost:3000/onboarding`
