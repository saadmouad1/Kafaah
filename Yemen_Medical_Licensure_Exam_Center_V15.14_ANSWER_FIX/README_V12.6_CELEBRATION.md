# V12.6 — Celebration Effects

Adds optional celebration effects to the working V12.5 Mock Exam / Practice build.

## Features
- Correct-answer celebration: 🎉/🎊 confetti + success sound when Sound is enabled.
- Successful Mock Exam celebration: larger confetti burst + success banner + success sound. Passing threshold: 60/100.
- Settings toggle: `Celebration Effects: ON/OFF`.
- Existing `Sound ON/OFF` remains independent.
- Existing Live Mock Score, score /100, correct/wrong/unanswered counts, correction, Smart Adaptive/Custom Mock, JSON database and analytics remain intact.
- Lightweight DOM/CSS effects; no external libraries.
