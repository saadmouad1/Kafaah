# Yemen Medical Licensure Question Intelligence — V11.5 Interactive Analytics

Based on V11.4 Professional UI.

## New in V11.5
- Intelligence major-section cards are clickable.
- Sub-specialty rows are clickable.
- Opens a lightweight bottom-sheet detail view.
- Shows accuracy, attempts, question count, topic count, sub-specialties, and topic-level performance.
- Topic performance is sorted from weakest to strongest to guide revision.
- "Practice This Area" launches focused practice for a selected sub-specialty.
- No external libraries; Android WebView/TrebEdit friendly.

All existing database, profession, year, date, governorate, practice, mock exam, question bank, JSON import/export, and analytics features are preserved.
