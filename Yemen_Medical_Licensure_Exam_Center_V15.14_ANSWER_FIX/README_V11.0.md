# Yemen Medical Licensure — V11.0 Premium Clean

This release is based directly on the stable V10.8 application engine.

## What changed
- Premium clean medical visual design.
- Lightweight emoji-based navigation and subject cards.
- Refined dashboard hero, KPI cards, quick actions, question cards, analytics cards and bottom navigation.
- Short interaction animations only; no heavy 3D, no external libraries, no backdrop-filter.
- Existing practice, mock exam, question bank, intelligence, JSON database and local storage logic preserved.

## Compatibility
Designed for Android WebView / TrebEdit / local HTTP preview.

Open `index.html` using the same Local Server workflow that worked with V10.8.
