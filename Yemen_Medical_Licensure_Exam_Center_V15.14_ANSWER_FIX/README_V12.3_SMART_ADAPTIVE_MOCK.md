# Yemen Medical Licensure Question Intelligence — V12.3

## Mock Exam Builder

The Mock Exam now has two modes:

1. **Smart Adaptive Exam** — prioritizes weak questions, previously missed questions, frequently attempted questions, and unseen questions.
2. **Custom Exam** — random selection from the selected filters.

Filters:
- Sub-specialty: All / specific
- Topic: All / specific
- Governorate: All / specific
- Exam Year: All / specific
- Exam Date: All / specific

Exam settings:
- Question count: 1–100
- Timed mode with configurable minutes
- Unlimited mode

The timer is disabled completely in Unlimited mode and shows `♾️ Unlimited` during the exam.

No external libraries were added. The app remains compatible with Android WebView/TrebEdit.
