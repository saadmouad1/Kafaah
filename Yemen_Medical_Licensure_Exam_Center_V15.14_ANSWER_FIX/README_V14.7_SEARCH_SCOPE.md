# V14.7 — Global Search Scope & Source Selection

## Question Bank Search
The Question Bank now supports four scopes:
- Current Selection — current app mode and profile filters.
- All Databases — Professional Licensure + Global Question Banks.
- Professional Licensure — all licensure questions.
- Global Question Banks — all global questions.
- Selected Sources — user-selected global question banks and/or professional licensure exam titles.

## Settings
Settings → Search & Analysis Scope allows selecting the scope. In Selected Sources mode, multiple Global Question Banks and Professional Licensure Exam Titles can be selected.

## Performance
Search continues to use IndexedDB as the source of truth with pagination. No full database is loaded into RAM.
