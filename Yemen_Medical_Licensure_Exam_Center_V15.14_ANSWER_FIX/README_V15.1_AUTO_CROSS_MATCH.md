# V15.1 Automatic Cross-Database Matching

Cross-Database Similar Questions now automatically compares all Professional Licensure questions against Global Question Banks. It no longer requires a search phrase.

The engine scores question wording, answer options, subject, topic, title and tags. IndexedDB `intelligenceTokens` is now a true multiEntry index (DB v7), fixing candidate retrieval. Results include both full questions and View Licensure / View Global / Practice Both actions.
