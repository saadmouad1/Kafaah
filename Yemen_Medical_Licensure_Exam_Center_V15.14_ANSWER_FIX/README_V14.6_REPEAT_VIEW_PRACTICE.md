# V14.6 — Repeated Question Viewer & Practice

- Exact repeated-question locations now show per-occurrence metadata.
- Each occurrence has **View Question** and **Practice** actions.
- Exact groups with multiple occurrences have **Practice Both / All Repeated Questions**.
- Similar-question groups can be practiced as a set.
- Question Viewer shows original question, original options, source answer, medically verified answer and explanation when available.
- Question Viewer loads the selected question directly from IndexedDB, so it is not limited by the RAM cache.
- Single-question practice also loads directly from IndexedDB.
